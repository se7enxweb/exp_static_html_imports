# Exponential Static Site Import

This extension imports a static site into the content tree, by content classes, and keeps it in step with the source.
This manual is being written along with the extension; the first chapters follow.

- [Importing a static site](importing-a-static-site.md): a first import, step by step
- [The import types](import-types.md): `--doc-html`, `--html-generic`, `--markdown`, `--sitemap-crawl`
- [Rules](rules.md): every setting of a type, in INI, YAML or PHP
- [Re-running an import](re-running.md): updates, edits in the CMS, removals, duplicates and redirects
- [Writing an import type](writing-a-type.md): the interface and how to register it
